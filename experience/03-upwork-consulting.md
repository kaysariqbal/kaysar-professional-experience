# Independent Consulting — Upwork

**Role:** Freelance Database Consultant  
**Period:** June 2021–July 2022

## Role overview

Delivered database consulting and engineering services to international clients, focusing on database administration, performance optimization, troubleshooting, and production operations.

## Technical responsibilities

- Provided advanced technical support across MySQL, MariaDB, PostgreSQL, MongoDB, and Redis.
- Performed database performance analysis, SQL query optimization, indexing improvements, and configuration tuning.
- Diagnosed and resolved database incidents involving replication, connectivity, resource utilization, availability, and operational stability.
- Designed and supported database replication, clustering, and high-availability architectures across multiple database platforms.
- Assisted clients with database installation, configuration, maintenance, upgrades, backup, recovery, and data migration.
- Conducted cross-platform database troubleshooting and provided recommendations for architecture, scalability, and operational best practices.
- Collaborated directly with international clients and engineering teams, managing technical escalations and support cases.

## Core technologies

MySQL, MariaDB, PostgreSQL, MongoDB, Redis, Oracle Database, Amazon Aurora.
