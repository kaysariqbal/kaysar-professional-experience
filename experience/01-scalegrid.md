# ScaleGrid

**Role:** Database Consultant – L3 Database Support & Multi-Platform Database Engineering  
**Period:** December 2022–April 2025

## Role overview

Provided Level 3 (L3) technical support and database consulting to enterprise clients across MySQL, PostgreSQL, MongoDB, and Redis environments.

## L3 Database Support & Multi-Platform Database Engineering

- Provided Level 3 (L3) technical support and database consulting to enterprise clients across MySQL, PostgreSQL, MongoDB, and Redis environments.
- Investigated and resolved complex production database incidents, escalations, performance bottlenecks, replication failures, connectivity issues, and data integrity problems.
- Performed advanced database troubleshooting and root cause analysis (RCA), implementing corrective and preventive measures to improve database reliability.
- Supported database installation, configuration, optimization, upgrades, migration, maintenance, backup, and recovery activities.
- Analyzed and optimized SQL queries, execution plans, indexing strategies, and database configurations to improve performance and scalability.
- Diagnosed MySQL replication, PostgreSQL streaming replication, MongoDB replica set, and Redis operational and connectivity issues.
- Investigated resource-related bottlenecks involving CPU, memory, storage, connections, locking, and concurrency.
- Monitored database health, availability, resource utilization, logs, and operational metrics to identify and address potential issues.
- Advised clients on database configuration, performance optimization, architecture best practices, and capacity planning.
- Collaborated with application development, infrastructure, and engineering teams to resolve complex cross-platform database problems.
- Managed technical escalations, incident documentation, RCA reports, and knowledge-sharing activities while meeting production support and SLA requirements.
