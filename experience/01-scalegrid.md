# ScaleGrid

**Role:** Database Consultant  
**Period:** December 2022–April 2025

## Role overview

Provided Level 3 (L3) database support and multi-platform database engineering for enterprise customers operating production database environments.

## Technical responsibilities

- Delivered L3 support across MySQL, PostgreSQL, MongoDB, and Redis environments.
- Investigated and resolved complex database incidents, performance bottlenecks, replication issues, connectivity failures, and data-integrity problems.
- Performed advanced database troubleshooting and root-cause analysis, with corrective and preventive actions to improve service disruption response.
- Monitored database health, availability, resource utilization, logs, and operational metrics to identify and address potential issues proactively.
- Analyzed and optimized SQL queries, execution plans, indexing strategies, and database configurations to improve performance and scalability.
- Troubleshot MySQL and PostgreSQL replication, MongoDB replica sets, and Redis operational/connectivity issues.
- Supported database installation, configuration, upgrades, maintenance, backup, recovery, and restoration.
- Diagnosed storage, memory, CPU, connection-management, locking, and concurrency-related performance issues.
- Advised customers on database architecture, configuration practices, capacity planning, and operational improvements.
- Collaborated with application, infrastructure, and development teams on cross-platform database issues.
- Managed technical escalations, incident documentation, and knowledge-sharing while working within service-level agreements.

## Platforms

MySQL, PostgreSQL, MongoDB, Redis.
