# Independent Database Consulting

**Role:** Freelance Database Consultant | Multi-Platform Database Engineering  
**Period:** August 2025–Present

## Role overview

I provide database consulting and engineering services to clients through freelance marketplaces, covering MySQL, MariaDB, PostgreSQL, Oracle, and MongoDB.

## Database Administration & Engineering

- Install, configure, administer, upgrade, and maintain databases across on-premises and cloud environments.
- Design and optimize database schemas, data models, indexes, and database objects.
- Perform database migrations, cross-platform data transfers, and modernization.

## Performance Engineering & Troubleshooting

- Optimize SQL queries, execution plans, indexing strategies, and database configurations.
- Investigate complex database issues, perform root cause analysis (RCA), and implement corrective solutions.
- Diagnose CPU, memory, storage, locking, concurrency, connectivity, and replication bottlenecks.

## High Availability, Backup & Recovery

- Configure and troubleshoot MySQL Replication, Galera Cluster, MySQL InnoDB Cluster, PostgreSQL Replication, Oracle Data Guard, and MongoDB Replica Sets.
- Implement backup, recovery, and restoration solutions.
- Support high availability, disaster recovery, and replication reliability.

## Cloud & Infrastructure

- Support database deployments across AWS, Google Cloud, Microsoft Azure, and on-premises infrastructure.
- Work with AWS RDS, Aurora, Linux systems, virtualization, monitoring, and Terraform-based infrastructure automation.

## Client Consulting & Technical Support

- Provide database consulting, advanced troubleshooting, and technical support.
- Collaborate with development and infrastructure teams on database design, performance, and migration.
- Deliver technical recommendations and implementation solutions aligned with client requirements.
