# REVE Systems

**Role:** Database Consultant  
**Period:** August 2022–November 2022

## Role overview

Worked on Oracle Database 19c administration and engineering across production and non-production infrastructure.

## Technical responsibilities

- Installed, configured, upgraded, and administered Oracle Database 19c environments.
- Performed day-to-day database administration, including instance monitoring, user and privilege management, tablespace administration, storage management, alert-log analysis, and routine maintenance.
- Implemented and maintained Oracle Data Guard configurations for high availability and disaster recovery, including physical standby setup, synchronization monitoring, switchover, and failover operations.
- Designed, implemented, and maintained enterprise backup and recovery strategies using Oracle Recovery Manager (RMAN), including full, incremental, and archive-log backups.
- Performed database recovery operations, backup validation, restore testing, and point-in-time recovery (PITR).
- Monitored database health and performance using Automatic Workload Repository (AWR), Active Session History (ASH), Automatic Database Diagnostic Monitor (ADDM), and Oracle Enterprise Manager.
- Performed SQL tuning, execution-plan analysis, indexing optimization, and database parameter tuning.
- Managed database security, including users, roles, privileges, auditing, and access controls.
- Troubleshot database incidents and maintained availability through proactive monitoring and preventive maintenance.
- Maintained technical documentation, operating procedures, and backup schedules.

## Platforms and tools

Oracle Database 19c, Oracle Data Guard, RMAN, AWR, ASH, ADDM, Oracle Enterprise Manager.
