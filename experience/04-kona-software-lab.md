# KONA Software Lab

**Role:** Senior Engineer Level-2 (Database)  
**Period:** February 2019–January 2021

## Role overview

Supported banking, fintech, digital payment, and enterprise platforms across Bangladesh and international markets. Responsibilities covered database administration, high availability, replication, backup and recovery, performance engineering, migration, and supporting infrastructure.

## Database platforms and high availability

- Installed, configured, and administered Oracle Database, Oracle RAC, Oracle Data Guard, MySQL, and MariaDB environments.
- Implemented database high availability, replication, clustering, backup, and disaster recovery strategies to support production service continuity.
- Worked with MySQL/MariaDB replication and Galera Cluster environments.
- Designed and maintained backup and recovery solutions using Oracle RMAN, Data Pump (EXPDP), and MySQL dump utilities.
- Performed database recovery, restore, and continuity-related activities.

## Performance engineering

- Conducted advanced database performance analysis and optimization using Oracle AWR, ASH, ADDM, execution statistics, and diagnostic tools.
- Used MySQL performance schema, slow-query logs, and error logs for performance investigation.
- Optimized database memory, instance configuration, SQL execution, indexing, and database objects through proactive and reactive tuning.
- Designed relational schemas and data models, including tables, views, synonyms, indexes, and referential-integrity constraints.
- Performed SQL development, query optimization, troubleshooting, and performance monitoring.

## Integration and migration

- Managed heterogeneous database connectivity and cross-platform data integration.
- Supported database migration across multiple relational database platforms.
- Tuned database server parameters and supported application/database performance monitoring.

## Systems and infrastructure

- Installed and administered Red Hat, CentOS, Oracle Linux, and Windows Server environments.
- Managed server infrastructure, hardware RAID, disk partitioning, LVM, filesystems, and virtualization.
- Developed shell scripts and Windows batch scripts for operational automation.
- Monitored infrastructure utilization and storage capacity.
