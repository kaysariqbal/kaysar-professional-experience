# KONA Software Lab

**Role:** Senior Engineer – Level 2 | Database Engineering & Administration  
**Period:** February 2019–January 2021

## Role overview

Supported banking, fintech, digital payment, and enterprise platforms across Bangladesh and international markets. Responsibilities covered multi-platform database administration, high availability, replication, clustering, backup and recovery, performance engineering, database upgrades, migration, and supporting infrastructure.

## MySQL, MariaDB & Percona Database Engineering

**Platform version:** MySQL 8

- Administered MySQL and MariaDB databases across on-premises and cloud environments.
- Managed Galera Cluster, MySQL InnoDB Cluster, and MySQL/MariaDB replication environments.
- Performed database instance performance tuning and SQL query optimization.
- Managed backup and recovery operations using mysqldump and MySQL Enterprise Backup.
- Administered database load balancing and connection pooling using HAProxy and MaxScale.
- Monitored and managed database environments using MySQL Enterprise Monitor.

## PostgreSQL Database Engineering

**Platform version:** PostgreSQL 10

- Administered standalone, replicated, clustered, and cloud-hosted PostgreSQL environments.
- Performed PostgreSQL instance tuning and SQL optimization using PostgreSQL Enterprise Manager (PEM) and pgBadger.
- Configured and maintained connection pooling and load balancing using PgPool and PgBouncer.
- Managed database backup and recovery using pg_dump, pg_dumpall, and pg_restore.
- Monitored PostgreSQL clusters using PostgreSQL Enterprise Manager (PEM).

## Oracle Database Engineering

**Platform versions:** Oracle Database 19c and 21c

- Administered Oracle standalone databases, Oracle Real Application Clusters (RAC), and Oracle Data Guard environments.
- Performed database instance performance tuning and SQL optimization.
- Managed backup and recovery using RMAN, EXPDP, and IMPDP.
- Performed Oracle database upgrade activities.
- Used AWR, ASH, ADDM, and Oracle Enterprise Manager for performance analysis, troubleshooting, and database administration.

## Integration, Migration & Data Modeling

- Managed heterogeneous database connectivity and cross-platform data integration.
- Supported database migration across multiple relational database platforms.
- Designed relational schemas and data models, including tables, views, synonyms, indexes, and referential-integrity constraints.
- Performed SQL development, query troubleshooting, and optimization across supported database platforms.
- Tuned database server parameters and supported application/database performance monitoring.

## Systems & Infrastructure

- Installed and administered Red Hat, CentOS, Oracle Linux, and Windows Server environments.
- Managed server infrastructure, hardware RAID, disk partitioning, LVM, filesystems, and virtualization.
- Developed shell scripts and Windows batch scripts for operational automation.
- Monitored infrastructure utilization and storage capacity.
