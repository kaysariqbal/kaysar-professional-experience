- The IELTS Academic Test Report Form is included as a redacted PNG; only the date of birth and candidate ID are obscured in the public image.
- Course-completion certificates and learning-path records are identified as training achievements. They are not represented as vendor-issued professional certifications unless the credential itself states that status.
- The Udemy AWS CloudOps Engineer Associate SOA-C03 record is a course-completion certificate, not evidence of passing the AWS certification exam.
- Credential IDs and verification references are included only where visible on the supplied documents. Where a certificate image is linked, it is stored in this directory.
