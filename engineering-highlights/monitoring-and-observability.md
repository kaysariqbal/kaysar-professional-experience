# Monitoring and Observability

Monitoring, performance visibility, and operational reporting have been part of my database and infrastructure responsibilities across consulting, banking, software, and telecommunications environments.

## Database monitoring and diagnostics

- Monitored database health, availability, resource utilization, logs, and operational metrics.
- Used Oracle AWR, ASH, ADDM, and Oracle Enterprise Manager for database performance diagnostics and administration.
- Used MySQL Performance Schema, slow-query logs, and error logs for performance investigation.
- Used PostgreSQL Enterprise Manager (PEM) and pgBadger for PostgreSQL monitoring and performance analysis.
- Monitored MySQL environments using MySQL Enterprise Monitor.
- Performed proactive monitoring, performance troubleshooting, and baseline-statistics analysis.

## Infrastructure and operational visibility

- Monitored infrastructure utilization, storage capacity, database availability, and resource consumption.
- Used Amazon CloudWatch for AWS infrastructure monitoring.
- Supported Oracle APEX reporting and operational dashboards at Mir Telecom.
- Investigated database and infrastructure incidents using performance, availability, log, and resource signals.

## Monitoring engineering
