# Cloud and Infrastructure Engineering

My experience includes supporting database workloads and infrastructure across on-premises, public-cloud, private-cloud, and hybrid environments.

## Cloud platforms

### AWS

- Administered AWS EC2 instances and managed instance snapshots.
- Worked with Elastic Load Balancing, Auto Scaling, VPC, Security Groups, Elastic IP, and CloudWatch.
- Administered AWS RDS database instances running MySQL, MariaDB, and Oracle.
- Supported Amazon Aurora and AWS-hosted database environments through database consulting and engineering engagements.

### Google Cloud and Microsoft Azure

- Provided database consulting and engineering for environments hosted on Google Cloud and Microsoft Azure.
- Supported database administration, performance, troubleshooting, migration, and operational requirements across cloud and on-premises environments.

### OpenStack and Huawei private cloud

- Worked with OpenStack components including Nova, Neutron, Keystone, Glance, Horizon, Cinder, Swift, and KVM in an R&D architecture and technical evaluation context.
- Participated in the Mir Cloud implementation team, working with Huawei FusionCloud 6.3 and FusionSphere OpenStack.
- Contributed to implementation activities involving virtual private cloud resources, compute, images, flavors, virtual data centers, security groups, firewalls, load balancing, and auto-scaling.
- Worked with Huawei Elastic Volume Service (EVS) concepts for block storage supporting Elastic Cloud Servers (ECS) and Bare Metal Servers (BMS).
